How it is judged

Answer keys
the true answer, its SQL and the traps, from raw SQL and labels
Blind
tool names and ids stripped; random, seeded answer order
Twice
judged in both orders; only agreeing verdicts count as wins
Checked
the judge verifies claims with read-only SQL
